# CP Calendar 🗓️

A simple Competitive Programming contest tracker built with **HTML, CSS and JavaScript**.

The project fetches contest data from the **Codeforces API**, finds the next upcoming contest, and displays its details in a clean card-based interface.

## 🌐 Live Demo

**[View CP Calendar](https://shivpratap-py.github.io/CP-Calendar/)**

## ✨ Features

* Fetches contest data from Codeforces
* Finds the next upcoming contest
* Displays:

  * Contest name
  * Contest duration
  * Contest date & time
  * Contest link
* Clean and simple UI
* Direct link to the Codeforces contest

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Codeforces API

## 🎯 Goal

The goal of this project is to build a single platform where competitive programmers can easily discover and track contests from different competitive programming platforms.

This project is also being developed as a way to learn and practice:

* JavaScript
* APIs
* Asynchronous programming
* DOM manipulation
* Array methods
* Date and time handling
* Frontend development
